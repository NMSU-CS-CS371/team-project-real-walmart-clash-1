# Real Walmart Clash

Real Walmart Clash is a tower defense-style game where the player must protect their base from waves of enemies. The goal is to survive as many rounds as possible while using turrets and troops to defend against multiple enemy types and boss enemies.

## Controls

- **WASD** — Move the player
- **E** — Interact / open the builder
- **Y** — Start the round
- **Esc** — Open or close the menu

## Gameplay

The player can use the builder to buy and place different turrets and troops around the map. These units help defend the base from enemies during each round. Enemies will move toward the base and attack anything blocking their path, so placement is important.

As rounds increase, more enemy types are introduced, including stronger enemies and boss-style enemies. Every few rounds, the difficulty increases, making enemies more dangerous and harder to stop.

## Objective

Defend your base for as long as possible and try to reach the highest round you can.

## Features

- Player movement with WASD
- Builder system for placing defenses
- Turrets and troops that attack enemies
- Multiple enemy types
- Boss enemies and stronger waves
- Round-based survival gameplay
- Leaderboard that displays previous runs
- Base health system
